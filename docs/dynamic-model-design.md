# DynamicLH2PoolX 동적 풀 모델

## 적용 경계

입력은 지표에 실제로 도달한 액체의 질량유량 `m_dot_in(t)`입니다. 저장용기
플래시와 분사 충돌로부터 이 유량을 추정하는 일은 별도 문제입니다. 계산영역은
수평이고 축대칭이며, 고체 또는 물 표면 하나로 구성됩니다.

## 보존식과 수치해

Dienhart JUEL-3155 식 4.2–4.3과 4.18에 따른 축대칭 얕은층 질량·운동량식을
환형 유한체적으로 풉니다. 상태는 각 셀의 깊이 `h`, 방사 운동량 `hu`, 누적
젖음 접촉시간입니다.

`partial(h)/partial(t) + (1/r) partial(r h u)/partial(r) = s - e`

`partial(hu)/partial(t) + (1/r) partial[r(hu^2 + g' h^2/2)]/partial(r)
= g' h^2/(2r) - friction`

셀 경계 유량은 보존형 Rusanov flux이고 CFL로 시간간격을 제한합니다. 마찰은
보고서의 층류 `nu*u/h`와 난류 Chezy `C*u^2`를 Reynolds 수 2320에서
전환합니다. 기본 Chezy 계수는 1e-3입니다. 외곽으로 빠진 질량을 별도 누적하여
전체 질량수지에 포함합니다.

유입은 중심 포물선 원천 또는 명시한 환형 원천으로 분배합니다. Dienhart 검증은
직경 0.4 m catch bowl을 반영해 반경 0.18–0.22 m 환형 원천을 사용했습니다.
계산상의 젖음 임계깊이와 보고용 전면 깊이는 분리됩니다.

## 증발 closure

고체 표면은 각 셀이 처음 젖은 뒤의 국소 접촉시간 `a`에 대해

`q(a) = k (T0 - Tsat) / sqrt(pi alpha a)`

를 사용합니다. 한 시간단계의 적분은 제곱근 분석해로 계산하므로 `a=0`의
특이점은 적분 가능하고 시간간격에 의존하지 않습니다. 선택한 임계열유속 상한과
명시적 실험 배율을 지원하며, 배율 사용 여부는 closure ID와 경고에 남습니다.

물 표면은 JUEL-3155 §4.2.2가 처음 약 50–60초에 허용한 일정 열유속 closure를
별도 형식으로 제공합니다. 일반적인 얼음 성장 모델이 아니며 사용 시 근거를
나타내는 calibration label이 필수입니다.

증발은 셀의 액체 깊이보다 클 수 없고, 젖음/건조 처리는 비음수입니다. CoolProp의
해당 압력 포화온도, 액체밀도, 점도와 잠열을 사용합니다. 물 위에서는
`g'=g(1-rho_LH2/rho_water)`, 고체에서는 `g'=g`입니다.

## 출력과 한계

각 출력시각마다 액체질량, 계산 wet area, 관측 연산자의 보고 반경·면적,
wet-area 평균깊이, 포화온도·밀도, wet-area 평균 열유속·증발 플럭스,
구간평균/마지막 내부 스텝 증발률·누계, 유입 누계, 영역 이탈 및 수치조정 질량과
closure ID를 기록합니다.
반경은 `reported_front_depth_m` 이상인 가장 바깥 셀 경계입니다.

현재 확산 경로는 초기 액체 재고를 받지 않고 선언된 유입으로 시작합니다. 비대칭
가지, 박리 액편, 파동·맥동, 복잡 지형과 물의 장시간 결빙을 해석하지 않습니다.
